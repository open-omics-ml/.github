# Open Omics ML

**What can modern machine learning tell us about omics biology?**

We apply current best-practice ML to published omics datasets, asking what the data reveal when new methods are applied. Built on the [ReproHack](https://www.reprohack.org/) tradition of reanalysis as positive scientific practice.

→ **[open-omics-ml.github.io](https://open-omics-ml.github.io)** — full project description, who it's for, and how to get involved.
